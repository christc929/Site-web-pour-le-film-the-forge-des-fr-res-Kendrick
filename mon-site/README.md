## Ce qu'il y a déjà

```
mon-site/
├── README.md              ← ce fichier
├── assets/
│   └── images/            ← 22 images temporaires, prêtes à l'emploi ✅
```

## Lancer le site

1. Ouvre `index.html` dans VS Code
2. **Clic droit → « Open with Live Server »**
3. Garde VS Code et le navigateur côte à côte : à chaque `Ctrl+S`, la page se recharge toute seule

---

## Les images

Les 22 fichiers de `assets/images/` sont des **images temporaires** : des rectangles orange
avec le nom du fichier écrit dessus. Ton site fonctionne dès le premier chapitre.

👉 Pour les remplacer par les vraies images du film :
[`ressources/guide-medias.md`](../ressources/guide-medias.md)

**Garde exactement les mêmes noms de fichiers**, sinon rien ne s'affichera.
